🆘 TROUBLESHOOTING

   App won't start?
      → heroku logs --tail
      → Check all config vars are set

   No usage data?
      → Verify HEROKU_API_KEY is correct
      → heroku config:set HEROKU_API_KEY=$(heroku auth:token)

   No emails?
      → Check SMTP credentials
      → Use Gmail App Password (not regular password)
      → Test: curl -X POST https://your-app.herokuapp.com/api/test-notification
